# LinkBook 0.1.0 beta 1

The first public build of **LinkBook**, a free and open-source desktop bookmark manager for Linux, inspired by Linkwarden. It's a beta: everything described here works and is tested, but expect rough edges, and keep an export of your bookmarks.

![LinkBook demo](https://raw.githubusercontent.com/0x0f2Root/LinkBook/v0.1.0-beta.1/assets/demo/linkbook-demo.gif)

## What's in it

- Four views of one library: **Board** (kanban, drag cards between categories), **Grid**, **Table**, and **List**
- Paste a link and its title, description, and preview image fill in automatically
- GitHub repository links show stars, forks, open issues, language, license, and last push
- Categories, tags, pinned and unread bookmarks, search, tag filter, and sorting
- **Import** any browser's bookmarks export (or drop the file on the window), and **Export** your library as standard bookmarks HTML
- Light and dark mode, following your system
- Starts with a clean, empty board. No account, no server, no telemetry; your bookmarks are a JSON file in `~/.config/LinkBook`, saved atomically with an automatic backup
- Native menus and keyboard shortcuts (Ctrl+N new, Ctrl+O import, Ctrl+F search, Ctrl+1–4 views)

## Downloads

All packages are for **x86-64 Linux** and contain the same app.

| File | For | Install |
|---|---|---|
| `linkbook_0.1.0-beta.1_amd64.deb` | Debian, Ubuntu, Mint, Pop!_OS, and derivatives | `sudo apt install ./linkbook_0.1.0-beta.1_amd64.deb` |
| `LinkBook-0.1.0-beta.1-x64.AppImage` | Almost any distribution, no install | `chmod +x LinkBook-*.AppImage && ./LinkBook-*.AppImage` |
| `LinkBook-linux-x64-0.1.0-beta.1.zip` | A portable folder | unzip, then run `./LinkBook-linux-x64/linkbook` |
| `SHA256SUMS` | Checking your download | `sha256sum -c SHA256SUMS --ignore-missing` |

The `.deb` adds LinkBook to your applications menu and a `linkbook` command. An `.rpm` for Fedora and openSUSE is planned for a later build; until then, the AppImage or zip should work there.

## Known limitations

- **Tested on PikaOS 4 (Ubuntu-based) under Wayland only.** The other formats and distributions should work, but haven't been tried on real installs yet. Reports are very welcome.
- **AppImage and zip on Ubuntu 24.04 and newer:** Ubuntu restricts the sandbox Chromium uses unless the app is installed. If the AppImage or zip build exits with a "SUID sandbox helper" or "namespace" error, use the `.deb` instead, or start it with `--no-sandbox` (this turns off a layer of protection).
- **GitHub stats** are limited to 60 lookups an hour without a token. See *Configuration* in the README to raise it to 5,000.
- **No automatic updates** yet. Download new versions from the Releases page.
- **No page archives** (screenshots or PDFs of saved pages) and **no sync** between computers yet.
